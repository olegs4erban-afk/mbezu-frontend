# Версия 2 (вариант B) — 23.10.2026

Новая главная и каталог по макету варианта B (холст «mbezu.ru — новая версия», дизайн-система Maison).

## Главная
- Первый экран — «две двери»: «Купить картину из наличия» и «Заказать картину под ваш интерьер».
  Основа — компонент 21st.dev «Split Hero With Image Cards» (hero-08, получен через коннектор, id 19078),
  переписан без motion/react, Tailwind, shadcn и аватаров. Фото сверху, бумажная этикетка снизу,
  вся дверь кликабельна, на телефоне двери друг над другом — обе кнопки в первом экране.
- Цели Метрики: `hero_stock_click`, `hero_commission_click`; ещё `paths_stock_click`,
  `paths_commission_click`, `tg_click` (шапка, меню, подвал, примерка, заявка).
  **Цели нужно создать в Метрике (JavaScript-событие с этими идентификаторами).**
- Ниже пять секций: новое в мастерской (8 свободных работ + подборки), два пути по шагам,
  примерка на стене, художник, вопросы и заявка (FAQ = FAQPage-разметка).
- Убраны: форма в первом экране, плитки-разводки, бегущая строка, манифест, блок цифр,
  упаковка, подписка, повторные CTA. Факты, которых нет в данных («3–5 дней», «15 лет»), не используются.

## Оболочка
- Одна шапка на все ширины, раскладку переключает CSS (раньше JS подменял шапку после загрузки — сдвиг).
- Подвал по-русски, без домашнего адреса ИП (он в оферте и реквизитах) и без Instagram.
- Липкая тёмная панель снята со всех страниц, кроме /painting.
- Кнопки, метки, бейджи — обычным текстом (без моноширинных капсов с трекингом), радиус кнопок 14px.
- Клиент гидратирует пререндер (hydrateRoot), а не перерисовывает его: LCP-картинка не грузится второй раз.
  Пререндер теперь `renderToString` (нужны разделители `<!-- -->` для гидратации).

## Каталог
- Серии — ссылки на свои адреса; фильтры не липкие; свободные работы всегда первыми;
  две колонки на телефоне; 24 работы + «Показать ещё» (в HTML — те же 24, адреса всех работ — в ItemList).
- Паспарту карточки больше не вытягивается высокими файлами — ряд карточек одной высоты.

## SEO
- `seoFor()` берёт title/description страниц Tilda из `seo/pages.json` (один источник),
  `applySeo()` на mbezu.ru head не трогает — «прыгающего» title больше нет.
- canonical /legal без `?section=`; из Organization убран Instagram.
- ItemList каталога и серий — только адреса работ (ListItem: позиция, адрес, название) в порядке
  каталога. Product + Offer по каждой работе уже отдаёт Tilda на странице товара (микроразметка,
  проверено на домене); разметка товаров на странице списка — против правил Google. Контейнер
  каталога: 73 → 44 КБ.
- Тесты: pages.json ↔ seoFor, числа в мета ↔ каталог, ItemList ↔ порядок каталога.
