## 3. Находки (дедуплицированы по 8 направлениям)

### КРИТИЧНО

**3.1. Весь домен отдаёт HTTP 402 — сайт не существует ни для людей, ни для роботов (подписка Tilda не оплачена)**
- **Где:** https://mbezu.ru — все URL: `/`, `/catalog`, `/about`, `/commission`, `/legal`, `/cart`, `/robots.txt`, `/sitemap.xml`, `/sitemap-store.xml`, `/_header-shop`, `/page142948046.html`, `/CATALOG`, `/home`, `/tracking`, `/journal`; `http://` и `www.` — тоже 402 без 301 (в одном из замеров `/commission` и `www` отдавали 403).
- **Факт:** 402 Payment Required на 20+ проверенных URL; тело 700 байт — фирменная заглушка Tilda «Please renew your subscription» (логотип со ссылкой на tilda.cc, картинка по `http://`); заголовки `x-tilda-server: 27/31`, `x-tilda-imprint`, `server: ddos-guard` — отвечает сама Tilda, это не бот-блокировка. Подтверждено 8 направлениями: curl (UA: Chrome, мобильный, YandexBot, Googlebot, пустой — все 402), Playwright/Chromium 1440×900 и 375×812 (белая страница, 1 текстовый узел, 0 картинок, 0 ссылок), повторы через 20–40 минут — стабильно. TTFB 42 мс — сервер отвечает мгновенно, но заглушкой. На заглушке нет даже meta viewport — на 375px она рендерится в 980 px.
- **Эффект:** 100 % потеря трафика, заявок и продаж; покупатель за картиной 25–130 тыс. ₽ видит «магазин закрыт за неуплату» на английском — удар по доверию; Метрика не собирает данные (длительность простоя потом не восстановить); 402 на robots.txt Яндекс трактует как недоступность сайта — страницы начнут выпадать из индекса в течение дней; вся SEO-работа s15 обнуляется, повторная раскачка займёт недели.
- **Как чинить:** немедленно оплатить/продлить тариф Tilda (Business — нужен для Store); включить автопродление; после оплаты убедиться, что все страницы снова 200 и счётчик Метрики 111308276 отдаёт хиты; запустить переобход в Вебмастере (страницы + оба sitemap). Никакая правка кода/контента не поможет.
- **Сложность:** минуты (оплата) + ~1 час пост-проверки.
- **Кто:** владелец (оплата в ЛК Tilda, руками); проверка — код.

**3.2. Товарные страницы отдают 404, а не 402 — выпадут из индекса первыми**
- **Где:** все 22 URL `/catalog/tproduct/…` (проверен `566542733172-wave-sepia`).

- **Сложность:** входит в пост-проверку 3.1 (~30 мин).

**3.3. Зеркало витрины на cdn.mbezu.ru открыто для индексации — при мёртвом основном домене может занять его место**
