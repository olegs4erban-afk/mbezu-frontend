## Откат версии 2

1. Клиент: `git revert` коммитов версии 2 в `main` (от `3a45379` до последнего) и push —
   GitHub Actions за минуту выкатит старую сборку на cdn.mbezu.ru (`/e/*.js`, `/e/style.css`).
2. Разметка: залить файл из корня этой папки в поле `code` нужного блока
   (MCP `update_record` с `only_field: "code"`, или вручную в редакторе Tilda) и опубликовать страницу.
3. Проверить на домене в инкогнито: первый экран, консоль без `[mbezu] hydration fallback`.

Порядок важен: сначала CDN, потом контейнеры — тогда расхождение старого клиента
с новой разметкой (и наоборот) длится минуты, а не часы. Расхождение не ломает страницу:
React перерисовывает её сам, но первый экран мигает.
